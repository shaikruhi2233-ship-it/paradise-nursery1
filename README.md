# Paradise Nursery Shopping Application

A responsive React and Redux Toolkit shopping cart for an online houseplant store.

## Features
- Landing page with company name and Get Started button
- Three plant categories with six products each
- Product thumbnails, names, prices, and Add to Cart buttons
- Redux cart state, dynamic cart count, quantity controls, and item removal
- Cart subtotal and Coming Soon checkout message
- Navigation links for Home, Plants, and Cart

## Run locally
1. Install Node.js (LTS).
2. Open this project folder in VS Code.
3. Open the terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal (usually http://localhost:5173).

Images are loaded from remote image URLs, so an internet connection is needed to display them.
